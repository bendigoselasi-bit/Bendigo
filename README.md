# Open-World Crime Drama

An original, cinematic 3D open-world crime-drama game built with **Unreal Engine 5**.

## Current direction

- **Genre:** Narrative-driven open-world crime drama and street-life story
- **Visual target:** High-fidelity, grounded 3D presentation
- **Audience:** Mature players, with a fictional target range of 30–50
- **Engine:** Unreal Engine 5
- **Initial platform assumption:** Windows PC; console targets can be assessed later
- **Development approach:** Blueprint-first playable prototype, with C++ for systems that need stronger structure or performance

## Project status

**Milestone 1 — Foundation**

The repository now contains the design and technical foundation. The next milestone is a small Unreal Engine vertical slice: one compact neighborhood, a player character, a camera, basic traversal, and one non-violent interaction.

## Development principles

1. Build an original setting, characters, story, and missions. Genre inspiration is fine; do not copy another game's protected characters, maps, missions, dialogue, branding, or assets.
2. Prove the core experience in a small vertical slice before expanding the world.
3. Prioritize readable controls, strong character writing, believable environments, and consistent performance.
4. Keep crime and conflict fictional and narrative-focused; emphasize player choice and consequences.
5. Track changes in Git with small, understandable commits.
